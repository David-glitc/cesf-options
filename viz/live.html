    CESF

    Compresses Monte Carlo futures of the underlying into operational events E_H(Q). Scores the put grid on all-path EV, then vetoes a short put when crash-mass ≥ 20%. That veto is the only extra rule versus RAW.

    RAW

    Same GBM paths, same contract grid, same EV / delta / gamma goal. No ε-graph and no crash veto. If CESF and RAW open the same strike, compression did not change the trade.

    microgpt-c

    Training and sampling are C only — vixhal-baraiya/microgpt-c, one file, libc, ~4k parameters, compiled with -DBLOCK_SIZE=48. Python writes teacher labels; it does not train the GPT.
